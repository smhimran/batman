# Split Batman benchmark — 8 November 2026

The focused skills retain the measured review outcomes and show modest token reductions against the previous combined skill. This run does not establish general superiority or a reliable efficiency improvement.

## Execution and recovery

The initial 80 attempts produced 31 final answers and 49 execution errors: timeouts and service/network failures including `workspace routing discovery failed`. A subsequent READY probe succeeded. One bounded error-filtered Promptfoo retry produced 54 successful calls and no new errors. The filter repeats some successful variants within affected tasks.

**All-attempt accounting: 134 attempts, 85 completed answers, 49 execution errors.** Five extra successful answers are retained. The balanced analysis uses the earliest two successful responses per task/variant, for 80 answers. That selection rule was recorded before inspecting retry outputs. These are success-conditioned quality scores, not 100% all-attempt reliability. Failures remain in the evidence.

## Setup and limits

Promptfoo used the existing authenticated Codex CLI, requested model `gpt-6-sol`, medium reasoning, fresh source-only Git workspaces, the same ten tasks, 300-second model budgets and the unchanged rubric. API-key environment variables were removed. Global skills were disabled with one consistent configuration. Frozen input/harness hashes remained unchanged. The actual backend model revision was not exposed.

The harness was adapted to map Guardian to `batman-review`, Detective to `batman-investigate`, Strategist to `batman-design`, Challenger to `batman-challenge`, and Executor to `batman-execute`. It copies the split package to the workspace and explicitly reads the relevant skill. The selector's routing and native invocation behavior are not evaluated. The prior combined snapshot was rerun contemporaneously. Superpowers remains a pinned reviewer-template comparison, not its full orchestration.

Grading uses anonymized candidate labels, a model judge and a coding-agent audit. It is not independent human validation. Evidence filtering and normalized grader excerpts have known limitations; original answers and raw traces are authoritative. The tasks are author-controlled development fixtures, not untouched external benchmarks. Recovery selection adds another limitation. Do not publish a claim of general superiority from these scores.

Offline checks passed: **30 Python tests and 11 Node tests**. The only repository implementation change for this run is split-layout support in the benchmark provider. Skill instructions were not modified. Installation was not changed. Nothing was committed, pushed or published.
