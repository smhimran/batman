# Batman updated-skills benchmark — 14 November 2026

The current working-tree skills scored **96.7/100 on reviews and 96.7/100 on broader tasks**. The previous 8 November snapshot, rerun contemporaneously, scored **100.0 and 96.7**, respectively. Review median reported tokens were essentially unchanged (**+0.2%**); broader-task median tokens fell **3.0%**. This small development suite does not demonstrate an overall improvement from the updates.

## Audit and interpretation

Every review variant identified the known core defects and accepted the correct-code control. Plain Codex lost five review criteria for omitted explicit repair recommendations: two bulk-query repairs, two archive-guard repairs, and one sync-order repair. Its additional unsuccessful trial claimed that the supplied unit test passed, but the raw trace showed only source inspection and a focused reproduction. The unsupported-claim flag was checked against the full raw trace, not merely the grader's filtered snippets. The outcome-score difference therefore should not be described as unique bug discoveries.

All six cancellation implementations passed independent hidden checks for repeat cancellation, one audit event, completed-job rejection, and reuse of the existing helper. No material unsupported claim was flagged in either Batman snapshot. The parent agent inspected every numerical deduction, the flagged claim, all updated Batman final answers, and representative raw tool evidence; grades remain model-assisted preliminary assessments, not independent human validation.

Updated answers included a reproduced retry sequence distinguishing provider acceptance from recipient delivery, an interrupted-sync checkpoint reproduction, and recoverable temporary-file replacement and rerun checks for the daily export. These are illustrative observations, not new scored tests of resilience or recovery. No new fixtures were added, and no instructions were tuned against the answers.

## Efficiency

Review median completed shell commands fell from **11 to 8.5**, while median uncached input rose from **6,179.5 to 9,054.5**. Broader-task commands rose from **7 to 8.5**, and uncached input fell from **6,524.5 to 6,223.5**. Median review seconds were **34.9 before / 32.9 after**; broader-task seconds were **41.6 / 44.8**. Concurrent execution makes these descriptive, not controlled latency measurements.

Reported tokens include cached input and are not subscription charges. Native review returned zero usage counters; its token usage is unavailable, not zero cost. Compared with plain Codex, updated Batman used **55.4% more** broader-task median reported tokens.

## Method, isolation, and execution accounting

Frozen inputs include the current uncommitted working-tree skills and the previous report's `inputs/batman` snapshot. All five focused skills differ between the snapshots, so results cannot isolate an individual wording change. Fixtures, rubric, provider and grading harness were frozen before model execution. The requested model was **gpt-6-sol**, medium reasoning, with two repetitions and a 300-second trial budget. Review/broader concurrency was three/two. Tool versions: **Codex CLI 0.166.0; Promptfoo 0.125.1**. The backend-resolved model revision was not exposed.

A frozen manifest disabled **261 global aliases and canonical paths** for all primary trials and graders. Raw-command audit found no unexpected comparator skill reads or global Batman reads in all 80 primary trials. Frozen hashes remained unchanged. This command-level audit is not a confidentiality boundary or proof against every possible contamination route.

The first restricted-host review batch produced **50 initialization failures and no model responses**. It could not start the in-process Codex app-server client. Those records are retained under `startup-failures/`; after the runner received the required host access, the complete fresh primary suite produced 80/80 answers. **Total trial accounting is 130 attempts, 80 answers, and 50 execution failures.** Grading calls are additional. All-attempt success rates, including those failures, are saved separately; primary scores must not be presented as rates across the entire execution history.

These are ten small, author-controlled development fixtures, with only five independent tasks per cohort. Two repetitions do not establish statistical significance or generalization. Superpowers means its pinned reviewer prompt on Codex, not its orchestration framework. Focused skills were invoked directly; the selector and installation changes were covered only by the earlier offline checks, not behavioral trials. A final live-source comparison found that `skills/batman/SKILL.md` changed after the freeze; the five evaluated focused skills remained byte-identical to the frozen inputs. The selector edit is outside this behavioral result. No authenticated Claude Code comparison was run.

Offline verification passed **31 Python tests and 11 Node prompt tests**. Existing edits were preserved. No installation, commit, push, or publication was performed.
